# Attribution and rights

Robattle Arena is an independent, unofficial fan prototype inspired by **Medabots AX for Game Boy Advance**. It is not an official game, remake, port, or product of the franchise rights holders, and no affiliation or endorsement is claimed.

## Project license

The [MIT license](LICENSE) covers the contributors' original source code and documentation to the extent they hold those rights. It does not grant rights to third-party names, logos, character designs, or other underlying intellectual property. It does not claim that the franchise-inspired models or screenshots are cleared for redistribution or commercial use.

The current sprite atlases and environment paintings were generated for this project; the earlier procedural models remain available as a rendering option. Their names and recognizable character designs refer to existing Medabots characters. Creating new artwork or geometry does not remove the underlying rights. See [asset provenance](docs/hd2d-art.md). No ROMs, extracted sprites, original-game recordings, or official model files are bundled.

The locally supplied `graphics_reference.png` is not part of the licensed release files. It is retained locally and ignored by Git. **Earlier commits contain that image.** Before publishing repository history, establish permission for it or prepare a reviewed source export that excludes it. History has not been rewritten.

The [art research](docs/character-art-research.md) links to reference sources for study; those photographs are not bundled assets. The README screenshot is captured from this prototype and depicts the same franchise-inspired designs.
